## Executive summary

Wave 1b is a **material improvement** over Wave 1: four plugin DLLs load on RE, MCP
Ping/Echo and `list_toolsets` are evidenced in committed logs, C++/Python Protocol
goldens exist, and the probe-plugin rollback workaround is retired in docs. Several
Wave 1 Critical findings are **closed or narrowed** (C-1 WS-03, C-2 Protocol goldens,
C-3 probe drift — shipping path claimed green).

What is **newly wrong** is mostly **honesty at the margins of mitigation**:

1. **R-03 shipping Validation** cites a log file that is **not in the repository** —
   the critic cannot verify the gate that unlocked Phase 1 exit for rollback.
2. **R-01 mitigation** in `RISK_REGISTER.md` tags Epic **DSL** round-trip as
   `[VERIFIED-RUNTIME]` thesis proof; RB-05 still marks implementation `in_progress` and
   explicitly defers `graph.schema.json` / `content_hash` bridge to POC A.
3. The **live MCP Echo path** still parses envelopes through `UeremcpMinimalEnvelope.h`,
   not `FUeremcpEnvelope` — the code golden tests actually exercise.

**Phase 1 exit verdict:** **Partially honest.** `docs/ROADMAP.md` documents the
deliberate relaxation from “four closed” to “one closed + three mitigated” with
reasoning. That is defensible for authorizing WS-06 P0 scaffolding. It is **not**
honest if read against the original binary gate in the same file’s “Original exit
condition” line, or `docs/POC_ACCEPTANCE.md` line 42 (“waits on Phase 1 exit”), which
was not updated.

### Major

#### M-1. Live MCP tools bypass golden-tested `FUeremcpEnvelope`

`Plugins/UEREMCP/Source/UeremcpCore/Private/UeremcpReferenceToolset.cpp` lines 29–88
call `Ueremcp::MinimalEnvelope::*`. `UeremcpCore.Build.cs` lines 30–32 document
intentional omission of `UeremcpProtocol` link. `UeremcpMinimalEnvelope.h` lines 1–5
still claim Protocol “do not link it yet” (stale — Protocol DLL loads per RE log).

`FUeremcpEnvelope` in `UeremcpEnvelope.cpp` line 9 uses `protocol_version` `"1.0"`
(schema pattern `^[0-9]+\.[0-9]+$` per `schemas/common/defs.schema.json` lines 8–12).
`MinimalEnvelope` line 20 emits `"1.0.0"`; Echo automation test line 113 sends
`"1.0.0"` and accepts it (`IsProtocolCompatible` compares major only, line 77–86).

**Impact:** C-2 Protocol golden parity does **not** cover the production MCP tool path.
Agents hitting Echo exercise a parallel, looser parser.

**Required action:** WS-03 link Core → Protocol; rewire Ping/Echo through
`FUeremcpEnvelope::ParseRequest` / `SerializeResponse`; align default version to
`1.0`; add Echo case to golden suite or ReferenceToolset test using schema-valid
request.

**Owner:** WS-03 (+ WS-05 for version constant single-source).

See `docs/proposals/ws-14-ws03-echo-protocol-rewire.md`.
